# Установка Stream Stats 1.0.2

1. Закройте OBS Studio 33.
2. Распакуйте архив так, чтобы папка `stream-stats` оказалась в каталоге плагинов OBS
   (рядом с папками `stream-notify` и `stream-chat-obs`).
3. Запустите OBS. Панель Stream Stats появится в меню **Док-панели** и по умолчанию
   откроется в нижней области. Её можно перетащить или изменить размер.

Панель предназначена для Windows x64 и OBS Studio 33. Архив содержит неподписанную
проверочную DLL. В панели доступны общий переключатель графиков 1/5/15 минут и
страница выбора языка. Самолётика и функции отправки сообщений здесь нет.
