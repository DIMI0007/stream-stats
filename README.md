# Stream Stats 1.0.0

Нативный Dock-плагин OBS Studio 33 для Windows x64. Показывает системную нагрузку,
суммарную статистику трансляции и запись в одной панели. Интерфейс адаптируется
к узкому Dock и к горизонтальному размеру стандартной панели статистики OBS.

## Показатели

- Система: CPU компьютера и процесса OBS, рабочий набор RAM OBS, свободная физическая RAM,
  FPS, среднее время рендеринга кадра, пропуски рендера и кодирования. GPU показывает
  загрузку самого занятого движка Windows GPU Engine, когда счётчик доступен.
- Трансляция: статус локальных выходов OBS, количество отдельных активных выходов,
  фактический суммарный битрейт по приросту отправленных байт, суммарный объём,
  сетевые потери. Каждый `obs_output_t` учитывается один раз. Запись и replay buffer
  исключены. Если активный выход похож на сетевой поток, но не даёт достаточно
  данных для точного учёта, рядом с битрейтом появляется `≥`.
- Запись: REC/PAUSED/OFFLINE, фактический битрейт, скорость, размер текущего файла,
  время, свободное место на диске текущего файла и оценка времени до заполнения.

Графики хранят 15 минут измерений в памяти; общий переключатель показывает последние
1, 5 или 15 минут. Снятие счётчиков и обновление интерфейса происходит раз в секунду.
Состояние и положение Dock сохраняет OBS, видимость, язык и выбранный интервал — плагин.
В блоке «Система» можно выбрать показатель графика: CPU ПК, CPU OBS, GPU или FPS.
Показатели в узкой панели размещаются сеткой; число потоков находится в заголовке
«Трансляция». Подсказка к нему показывает названия активных выходов OBS, если они доступны.
Нижняя строка трафика относится к самому Stream Stats и остаётся нулевой, поскольку
плагин не делает сетевых запросов; переданные видеоданные показаны в блоке трансляции.

**Ограничения:** локальное состояние OBS не подтверждает доступность эфира зрителям.
Время записи начинается, когда Stream Stats впервые видит активную запись, и исключает паузы.
Если точный текущий файл недоступен через настройки выхода OBS, его размер показывается
со знаком `≈` как оценка по обработанным байтам. Прогноз диска доступен при известном
каталоге записи и ненулевой скорости записи.
Счётчик GPU может отсутствовать из-за драйвера или конфигурации Windows; тогда показывается `—`.
Плагин не обращается к API стриминговых платформ и не отправляет анонсы.
