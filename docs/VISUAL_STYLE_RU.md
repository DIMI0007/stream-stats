# Визуальный стиль плагинов Stream

Эталон палитры и общих элементов — **Stream Notify**. Stream Chat и Stream Stats используют те же базовые цвета, размеры шапки и подвала. Цвета платформ и отдельные цвета графиков сохраняют смысл показателей.

| Элемент | Цвет |
| --- | --- |
| Фон панели | `#080f18` |
| Карточка | градиент `#101925` → `#0b131e` |
| Рамка карточки | `#263244` |
| Основной текст | `#dfe8ff` |
| Вторичный текст | `#8ea1c0` |
| Заголовок панели | `#e7fff4` |
| Ссылка и голубой акцент | `#59dfff` |
| Бирюзовый акцент | `#72e9f4` |
| Успех и активность | `#07df91` |
| Ожидание и предупреждение | `#ffdc45` |
| Ошибка и запись | `#ff8484` |
| Кнопка | градиент `#202a3b` → `#141d2b`, рамка `#39465d` |

Общая шапка: внешние отступы 8 px, логотип 28×28 px, промежуток 7 px, шестерёнка 30×28 px с иконкой 19×19 px. Между шапкой и первым блоком — 5 px. Подвал: строка автора 11 px и строка трафика 10 px; ссылка выделяет только имя автора.

Узкие Dock-панели должны переносить пояснения, подписи и состояния внутри карточек. Однострочные поля ввода и числовые значения остаются однострочными. При уменьшении ширины нельзя перекрывать кнопки, иконки или соседние показатели.
